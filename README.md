# 🧮 JavaScript Calculator

A simple and mobile-friendly calculator built using HTML, CSS, and JavaScript.  
It supports basic arithmetic operations with a clean and responsive UI.

---

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear / Reset

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- Vanilla JavaScript
